# 丸つけクイズ テンプレート

Fuglen バーテンダークイズの仕組み（カテゴリ選択・選択式／記述式／画像問題・データ表からの自動出題・教科書・問題編集）から中身をすべて外し、どんな題材にも使えるようにしたクイズアプリのひな形です。

答案用紙に赤ペンで丸つけをする動きを軸に、次のモーションが入っています。

- タイトルの1文字目を赤ペンで囲む書き込み
- 出題前の「3・2・1・はじめ」カウントダウン
- 正解で ◯、不正解で ✕ が手描きで書き込まれ、正解の選択肢に蛍光ペンが引かれる
- 解答状況をマークシートのように塗りつぶす進捗表示
- 3問連続正解の表示
- 採点画面で得点がカウントアップし、赤ペンの丸と先生のはんこが押される
- 画面切り替え、問題送り、要点ノートの開閉

端末の設定に合わせて「答案用紙（ライト）」と「黒板（ダーク）」が切り替わり、画面下の「表示」から手動でも変えられます。動きを減らす設定の端末では、アニメーションを省略します。

## 別のクイズにする手順

1. `quiz.config.js` を開く
2. `app` の `title`（アプリ名）、`subject`（科目欄）、`storageKey`（保存領域の名前。クイズごとに別の名前にする）を書き換える
3. `categories` にカテゴリを並べる（`key` は英数字、`name` は表示名）
4. `questions` に問題を書く（書き方はファイル内のコメントを参照）
5. 必要なら `decks`（データ表からの自動出題）、`notes`（要点ノート）、`grades`（はんこの文言）も書き換える
6. 保存して `index.html` をブラウザで開く

`index.html` は書き換える必要はありません。

## アプリ上で作った問題を配る

「問題を編集」で追加・修正した問題は、その端末にだけ保存されます。ほかの人にも配るときは次のようにします。

1. 「問題を編集」→「書き出す」→「コピーする」
2. `quiz.config.js` の `questions: [ ... ]` の中身を、コピーした内容と入れ替える

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面・動き・出題エンジン（触らなくてよい） |
| `quiz.config.js` | 問題・カテゴリ・色などの中身（ここだけ書き換える） |
| `manifest.json` / `sw.js` / `icon.svg` | ホーム画面に追加して、オフラインでも使うための設定 |

## 色を変える

`quiz.config.js` の `theme` で色を上書きできます。

```js
theme: {
  light: { mark: "#1F6FEB" },   // 赤ペンの色（ライト）
  dark:  { mark: "#7FB2FF" }    // 赤ペンの色（ダーク）
}
```

使えるキーは `paper`（背景）、`sheet`（用紙）、`ink`（文字）、`ink-2`（補助文字）、`rule`（罫線）、`mark`（赤ペン）、`hi`（蛍光ペン）などです。
